# Kasper AI — Gemini 3.5 Flash

Telegram-бот: чат с контекстом, поиск Tavily, сайты, агент, голосовые,
напоминания и «Теневой город». Python 3.11, aiogram 2.25.2.

## Запуск на Render

1. Выберите **Web Service**, репозиторий `rachimanna/KasperAI`, ветку `main`.
   Для нового сервиса можно использовать Blueprint из `render.yaml`.
2. Build Command: `pip install -r requirements.txt`.
3. Start Command: `python main.py`. Health Check Path: `/`.
4. В **Environment** установите/обновите:

| Переменная | Значение |
| --- | --- |
| `PYTHON_VERSION` | `3.11.14` |
| `TELEGRAM_BOT_TOKEN` | Токен вашего бота из BotFather |
| `GEMINI_API_KEY` | Ваш ключ Google AI Studio с доступом к модели |
| `GEMINI_MODEL` | `gemini-3.5-flash` |
| `GEMINI_FALLBACK_MODELS` | `gemini-3.7-flash` — запасная модель при перегрузке основной |
| `GEMINI_THINKING_LEVEL` | `medium` (или `high` для более сложных задач) |
| `AI_PROVIDERS` | `gemini,groq,cerebras` |
| `ENABLE_LOCAL_TTS` | `false` |

Дополнительно: `TAVILY_API_KEY` для интернет-поиска; `GROQ_API_KEY` для
распознавания голосовых и `GROQ_MODEL` для резервного AI; `ADMIN_ID` — ваш
Telegram ID. Без ключа резервный провайдер пропускается. Старые значения
в Environment имеют приоритет над кодом: обязательно поменяйте модель
и очередь провайдеров. `render.yaml` автоматически не меняет существующий
сервис, созданный вручную.

5. Если сервис приостановлен — возобновите его. Выполните
   **Manual Deploy → Clear build cache & deploy** после смены Python.
6. Остановите другие копии бота с тем же токеном: Telegram polling
   должен работать только в одном процессе. Проверьте лог
   `Kasper AI is running.`, затем `/start`, `/status` и обычный вопрос.

Ключи задаются только в Environment, не в файлах GitHub. Доступность и
квота Gemini проверяются вашим ключом при первом реальном запросе.

## Память и ответы

В контекст входят 30 последних сообщений и конспект ранней переписки.
Цитируемое сообщение передаётся модели. Быстрые сообщения одного чата
обрабатываются последовательно; конспекты не перезаписывают друг друга.

В личке: `/remember текст` сохраняет факт или предпочтение, `/memory`
показывает записи, `/forget` удаляет сохранённые факты (историю не удаляет).
Сохранённые личные факты не передаются в групповой чат.

## Голос и ограничения хостинга

Распознавание голосовых использует Groq. На небольшом сервере ответ
приходит текстом, локальная озвучка отключена по умолчанию.
Для Silero на сервере с достаточной памятью установите
`pip install -r requirements-voice.txt` и `ENABLE_LOCAL_TTS=true`.
Модель загружается только при первом голосовом ответе.

Free Web Service Render засыпает после 15 минут без входящего HTTP-трафика:
Telegram long polling не предотвращает сон. Доставка ответов и напоминаний
во время сна не гарантируется. SQLite на free-инстансе временная:
после нового деплоя/рестарта данные могут пропасть. Для постоянной работы
нужен постоянно работающий инстанс и persistent disk; установите
`DATABASE_PATH=/var/data/kasper.db` при диске, смонтированном в `/var/data`.
Не указывайте этот путь без подключённого диска. Пользовательская БД
не входит в GitHub, это обновление не переносит её с прежнего сервера.

## Проверка

```bash
pip install -r requirements.txt
python -m unittest discover -s tests/unit -v
python -m compileall -q config database memory projects router telegram main.py
```

Тесты из `tests/unit` используют временную SQLite и поддельные HTTP/Telegram
ответы; реальные сообщения не отправляются. Ручная проверка Gemini с вашим
ключом: `python test_gemini.py`; всего роутера: `python test_ai.py`.

Исправлены: несовместимые зависимости/Python, разбор истории, гонка
создания SQLite-соединения, повторное подтверждение агента, недопустимые
ночные ходы, потеря напоминаний при сетевой ошибке, утечка дочернего
процесса загрузчика при отмене, загрузка TTS при старте, строковые false
в классификаторах и повторная отправка сообщений при ошибках сети.

При HTTP 429/5xx после повторных попыток бот пробует запасную Gemini с тем же ключом. Каждый новый запрос снова начинается с основной модели. Пустое `GEMINI_FALLBACK_MODELS` отключает переключение. Доступ к запасной модели также зависит от ключа и квоты Google. Логи `model=... OK` показывают, какая Gemini фактически ответила.

## Исправления напоминаний, агента и игры

«Через 2 дня в 10 утра» учитывает точное время; явная прошедшая дата
вызывает отказ без обращения к AI. При ошибке AI запрос возвращается
в дневной лимит, а вопрос без ответа не сохраняется в истории.
Длинные ответы агента делятся на части; сессия очищается при ошибке.

Лобби и запуск игры защищены от одновременных нажатий. При обновлении
базы удаляются повторные записи участников (сохраняется первая),
создаётся уникальный индекс. Остановить игру может её создатель,
администратор группы или администратор бота. Для старых игр без
сохранённого создателя доступны только администраторы. После остановки
ожидание последних слов не запускает голосование или новую ночь.
